# 7つの切り口（技法）

同じ主張でも、技法を替えると読後の温度が変わる。優劣はなく、目的との相性だけがある。
お題の例は「言語化力が低い人は、仕事ができない」。

## 目的 → 技法の早見表

| 目的 | 技法 |
|---|---|
| 早く理解してほしい | ① 直球型 |
| あるあるで頷かせたい | ② 特徴3リズム型 |
| 情景で感情を動かしたい | ③ 再現VTR型 |
| 説教臭さを消したい | ④ 他者引用型 |
| 違いを一瞬で見せたい | ⑤ 天秤対比型 |
| 損得で行動を変えさせたい | ⑥ 電卓型 |
| 記憶に残したい | ⑦ 通訳型 |

## ① 直球型 — まっすぐ言う
- 例: 「言語化力が低いと、指示・報告・相談の精度が下がり、業務効率に悪影響を及ぼします」
- 強み: 正確、誤解がない。謝罪文・障害報告・社内通達など「心を動かしてはいけない文章」専用。
- 注意: 記憶に残らない。感情訴求の文章には不向き。

## ② 特徴3リズム型 — 特徴を3連で畳みかける
- 例: 「主語を抜き、理由を省き、具体例を考えない。それが"言語化をサボる人"」
- 強み: 3連の順番を「段階的に当てはまる人が増える」設計にすると、読者のどこかに刺さる。語呂ではなく"網"の技術。
- 注意: 3つの順序に意味がないと、ただの羅列になる。

## ③ 再現VTR型 — あの日の現場を流す
- 例: 「上司から『いい感じにしといて』と資料を渡されたのに、金曜18時に『なんか違う』だけが返ってきて、休日がなくなった」
- 強み: セリフと時刻があると文章が勝手に動く。情景で感情を動かせる。
- 注意: 長くなる。最後に"発見"を置かないとただのグチ。ネタ（実際のセリフ・時刻）が必要。

## ④ 他者引用型 — 教わった言葉で語る
- 例: 「10代のころに教わった『言語化をサボる人は信用しない方がいい』という言葉を、自分の信念にしている」
- 強み: 言ったのは他人なので押し付け感が消える。自分を大きく見せずに説教できる。
- 注意: 作り話は一発でバレる。実話・実在の言葉だけ使う。引用元が無いなら提案しない。

## ⑤ 天秤対比型 — 二つ並べて選ばせる
- 例: 「高い人は『明瞭な言葉』で仕事を任せてくれるが、低い人からは『察して』が漂う。前者が仕事なら、後者は占い」
- 強み: 構造が一瞬で伝わる。「自分はどっち側か」を突きつける踏み絵。プレゼン向き。
- 注意: 多用すると「また二択か」と飽きられる。世界は白黒より灰色が多い。

## ⑥ 電卓型 — 感情を数字に翻訳する
- 例: 「曖昧な指示1回で確認2往復と手戻り1回、約30分の損。毎日なら年間120時間＝丸5営業日。『察する』には人件費がかかる」
- 強み: 正論では動かない人も損得なら動く。上司・経理向き。
- 注意: 数字が1つ雑だと全体が疑われる。叩かれやすい。前提と計算式を明示する。
- 載せる前に必ず自分で再計算する。元ネタの例も鵜呑みにしない（例: 「年間120時間＝丸5営業日」は8時間換算だと15営業日で誤り）。

## ⑦ 通訳型 — 知らない話を、知ってる世界に訳す
- 例: 「ジェスチャーゲームで当てられなかった側にキレる人はいない。伝わらない原因は動きのほうにあるから。なのに言語化力が低い人は、察しなかった側を怒る」
- 強み: 記憶に残る。例えは"自分の世界"でなく"相手の世界"から拾う（ゴルフ好きにはゴルフ、料理する人には台所）。
- 注意: 例えが遠いと誤訳になる。読者像が不明なら提案しにくい。

## 根っこの考え方
文章力の正体は「切り口の在庫数」。同じ一文を何通りで書けるかがそのまま文章力になる。
だから1つの主張に対して、技法を替えた複数案を出せること自体が価値になる。
